# A Lazy Data Engineer

This repository contains a collection of data engineering projects built to explore real-world data pipelines, processing systems, and analytics workflows.

Each project is organized in its own folder and includes its own documentation, architecture, setup instructions, and implementation details.

## Projects

| Folder                                                           | Description                                                                                                                                                                                                               |
| ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`indonesian-firewatch`](./indonesian-firewatch)                 | Data engineering pipeline for processing and analyzing Indonesian wildfire and fire hotspot data, with a focus on building reliable data ingestion, transformation, and analytics workflows.                              |

> See the `README.md` inside each project folder for setup instructions, architecture, and implementation details.

More projects will be added in the future.
